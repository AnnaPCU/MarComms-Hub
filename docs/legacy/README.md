# Contexto histórico — versión original del Hub (abril 2026)

Documentación de la **primera versión** del Marcomms Hub: un archivo único (artifact de Claude / HTML standalone con JSONBin) que solo trackeaba webinars.

Esa versión ya fue reemplazada por la app actual (Vite + React + Supabase). Se conserva acá únicamente como referencia de decisiones tomadas y reglas de negocio que siguen vigentes (por ejemplo, los offsets de fechas de los mailings).

| `historial-conversacion-original.md` | Transcript del chat original donde nació el Hub |
